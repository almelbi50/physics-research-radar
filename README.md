# نبض الأبحاث — وكيل النشرة البحثية الأسبوعية

وكيل ذكاء اصطناعي يعمل أسبوعيًا عبر GitHub Actions:

1. يبحث فعليًا على الويب عبر **Tavily Search API** (مجاني بالكامل، بدون
   بطاقة ائتمان — انظر القسم 2 أدناه) في المصادر العلمية الموثوقة (APS,
   Nature, Physics World, EurekAlert, CERN, MIT, Stanford... إلخ) عن آخر
   7 أيام من الأخبار البحثية، باستعلام منفصل لكل مجال من المجالات الـ12
   الفيزيائية.
2. يمرّر نتائج البحث الحقيقية فقط (العناوين والروابط والتواريخ كما وردت
   حرفيًا من محرك البحث) إلى **Gemini** الذي يتحقق من كل خبر ويفرزه
   وينسّقه — دون أي اعتماد على معرفة النموذج المخزّنة، والتزامًا الصارم
   بتعليمات `instructions.md` (لا ترجمة، لا إعادة صياغة، لا اختلاق
   معلومات).
3. يحفظ النشرة الناتجة كملف Markdown داخل `reports/` ويرفعه (commit) إلى
   المستودع تلقائيًا.
4. ينشرها **كمسودة (draft)** على ووردبريس (phy-lab.com) ضمن تصنيف
   "نبض الأبحاث" (تصنيف فرعي تحت "آفاق الفيزياء") — لمراجعتك والنشر
   يدويًا، وليس نشرًا فوريًا مباشرًا.

هذا مستودع مستقل تمامًا عن أدوات الأتمتة الحالية (`auto_physics.py`،
`physics_pipeline.py`، `experiments_pipeline.py`) ولا يتعارض معها.

> **لماذا Tavily وليس ميزة Google Search grounding المدمجة في Gemini؟**
> ميزة الـ grounding غير متاحة إطلاقًا على الخطة المجانية لـ Gemini API
> (توثيق Google الرسمي يذكرها صراحة كـ "Not available" على Free tier —
> تتطلب ترقية مدفوعة). لتفادي أي تكلفة، يستخدم الوكيل بدلاً منها Tavily
> Search API، وهي خدمة بحث مصممة خصيصًا لوكلاء الذكاء الاصطناعي، مجانية
> بالكامل حتى 1000 طلب بحث شهريًا بدون الحاجة لبطاقة ائتمان — وهو أكثر
> بكثير مما يحتاجه تشغيل أسبوعي واحد.

## 2. إعداد المفاتيح السرّية (Secrets)

في المستودع على GitHub: **Settings → Secrets and variables → Actions →
New repository secret**، أضف:

| الاسم | القيمة |
|---|---|
| `GEMINI_API_KEY` | مفتاح Google Gemini API الخاص بك (أنشئه من aistudio.google.com/apikey) — الخطة المجانية تكفي، لأن الوكيل لم يعد يستخدم أداة grounding المدفوعة |
| `TAVILY_API_KEY` | مفتاح Tavily Search API المجاني — سجّل مجانًا (بدون بطاقة) من tavily.com، ثم انسخ المفتاح من لوحة التحكم (يبدأ بـ `tvly-`) |
| `WP_URL` | `https://phy-lab.com` |
| `WP_USER` | اسم مستخدم ووردبريس الذي له صلاحية إنشاء مقالات |
| `WP_APP_PASSWORD` | كلمة مرور تطبيق ووردبريس (وليست كلمة مرور حسابك) |

### كيف تنشئ كلمة مرور تطبيق ووردبريس؟

في لوحة تحكم ووردبريس: **Users → Profile → Application Passwords** → أدخل
اسمًا مثل `physics-radar` → **Add New Application Password** → انسخ
القيمة الناتجة فورًا (لن تظهر مرة أخرى) واستخدمها في `WP_APP_PASSWORD`.

> تأكد أن REST API لووردبريس (`/wp-json/`) غير محجوب بجدار حماية أو إضافة
> أمان (بعض إضافات التقوية تمنع `wp-json` بشكل افتراضي).

### متغيرات اختيارية (Repository Variables، وليست Secrets)

في **Settings → Secrets and variables → Actions → Variables** يمكنك
ضبط، عند الحاجة فقط:

- `GEMINI_MODEL` — لتحديد نموذج مختلف عن الافتراضي (`gemini-3.6-flash`)
  في `agent.py`. راجع القائمة المحدّثة في
  <https://ai.google.dev/gemini-api/docs/models> بين حين وآخر — نماذج
  Gemini تُستبعد أحيانًا فجأة من الاستخدام لحسابات معينة (كما حدث مع
  `gemini-2.5-flash`)، فإن فشل التشغيل بخطأ `404 NOT_FOUND` يذكر نموذجًا
  بديلًا، حدّث هذا المتغير أو القيمة الافتراضية في `agent.py`. لا حاجة
  لدعم أداة `google_search` بعد الآن لأن البحث يتم عبر Tavily.
- `WP_CATEGORY_NAME` — إن أردت تصنيفًا مختلفًا عن "نبض الأبحاث".
- `PUBLISH_STATUS` — غيّرها إلى `publish` لاحقًا إذا قررت النشر المباشر
  بدل المسودة (الإعداد الافتراضي حاليًا: مسودة للمراجعة).

## 3. التفعيل والتجربة

1. من تبويب **Actions** في المستودع، فعّل الـ workflows إذا طُلب ذلك.
2. جرّب التشغيل يدويًا أولًا: **Actions → Weekly Physics Research Radar
   → Run workflow**.
3. راقب السجل (logs) للتأكد من نجاح البحث والنشر — سطور
   `[Tavily] <المجال>: N نتيجة فريدة` تؤكد أن البحث الحقيقي يعمل قبل
   وصول الدور لـ Gemini.
4. افتح ووردبريس → **المقالات → المسودات** وستجد النشرة الجديدة جاهزة
   للمراجعة والنشر.
5. تحقق من `reports/` في المستودع — ستجد نسخة Markdown مؤرشفة من كل
   نشرة أسبوعية.

الجدولة الافتراضية: كل يوم اثنين الساعة 08:00 بتوقيت الرياض. لتغييرها،
عدّل سطر `cron` في
`.github/workflows/weekly-radar.yml` (استخدم <https://crontab.guru>
للمساعدة — تذكّر أن GitHub Actions يستخدم توقيت UTC).

## 4. ملاحظات مهمة

- **`instructions.md` هو مصدر الحقيقة**: أي تعديل تريده على نطاق البحث،
  المجالات، المصادر، أو قالب التقرير — عدّله في هذا الملف مباشرة. أما
  الكلمات المفتاحية الإنجليزية المستخدمة فعليًا لبناء استعلامات Tavily
  فموجودة في قائمة `DOMAINS` داخل `agent.py` (يجب تحديثها يدويًا إذا
  أضفت مجالًا جديدًا في `instructions.md`).
- الوكيل مُلزم صراحة بعدم اختلاق أي معلومة: يُمرَّر لـ Gemini فقط نتائج
  Tavily الحقيقية (عناوين/روابط/تواريخ كما وردت حرفيًا)، ويُمنع عليه
  إضافة أي شيء غير موجود فيها — لا الاعتماد على معرفته المخزّنة مسبقًا.
- **التكلفة: صفر عمليًا.** Tavily مجاني حتى 1000 طلب/شهر (التشغيل
  الأسبوعي الواحد يستهلك ~24 طلبًا فقط)، وGemini يعمل هنا على الخطة
  المجانية العادية (بدون grounding) التي لا تتطلب فوترة.
- إذا لم يجد الوكيل تصنيف "نبض الأبحاث" في ووردبريس عبر الـ REST API،
  سينشر المسودة بدون تصنيف ويكتب تحذيرًا في السجل — تأكد من إنشاء هذا
  التصنيف على الموقع (ويُفضّل جعله تصنيفًا فرعيًا تحت "آفاق الفيزياء").
